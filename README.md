# TaskAnalyzer

Projeto desenvolvido para a disciplina Bootcamp III.

## Objetivo
Implementar um sistema para analisar tarefas, calcular indicadores e validar dados de entrada.

## Tecnologias
- Python 3.11+
- pytest
- Git e GitHub
- Assistência de Inteligência Artificial

## Estrutura
- specs/: especificação do sistema
- tests/: testes automatizados
- src/: código-fonte
- CONTEXT_RULES.md: regras de governança da IA

## Execução dos testes
Instale as dependências:

pip install -r requirements.txt

Execute os testes:

python -m pytest -v
